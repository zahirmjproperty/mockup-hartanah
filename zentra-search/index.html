What is reachable without login

Coverage by platform

Each platform has a different open door. Matching the method to the platform is the whole trick.

Plus a web-search fallback (site:threads.com "keyword") that reaches indexed public posts across all six at once. Logged-out results are a sample (~20–30 posts per query), not the full population.

Retrieval chain

How a query is answered

Cheapest method first; the browser render only when the platform needs JavaScript.

1Web search

Indexed public posts, cheapest. Returns real post URLs plus snippets.

2Page extract

Reads the returned URLs. Works for LinkedIn, Facebook, Instagram, X.

3Headless render

The only reliable path for Threads and TikTok, and Instagram when rate-limited.

4Embed API

Structured single item: X syndication / oEmbed, TikTok oEmbed.

Boundaries

Public data only

Rules this module enforces

  • Never logs in, never uses a user session — that is the fastest route to a restricted account.
  • No personal contact lists. Names, jobs and photos are personal data even when public; PDPA applies to commercial use.
  • Scoped to companies, Pages, hashtags, ads and job posts — not people.
  • Official APIs preferred for long-term use: Meta Threads API, X API v2, Meta Ad Library API.
  • Every result is labelled with its platform, and any gap is stated. A sample is never presented as the whole population.
