Sign in with Zentra

How a different Zentra system (for example Zentra Finance, or Zentra Works) asks for your identity — without creating a second password.

  • 1
    You open another Zentra systeme.g. works.zentrapropertygroup.com
  • 2
    It sends you to Zentra ID“Sign in with Zentra” — the same login screen
  • 3
    You approve access onceThe screen lists exactly what the system will be allowed to read
  • 4
    You are back where you started, signed inNo new account, no new password
OAuth 2.1 / OpenID Connect (PKCE) → Zentra ID issues a signed token → The system reads only the scopes you approved → Revoke any system from My Account at any time
Phase 3. While every system lives on one domain (one website), signing in once is automatic. “Sign in with Zentra” is for systems on other domains or servers — Zentra Finance (ERPNext) and Zentra Works are the first candidates.
